TriCaster Mini Boot Camp Quiz Lab

HOW TO USE:
1. Keep index.html in this folder.
2. Open index.html in a modern browser.
3. Student progress is saved in that browser/device using localStorage.
4. Students can print/save their final results screen if you need proof of completion.

CANVAS NOTE:
Canvas generally will not execute arbitrary JavaScript pasted directly into an Assignment/Quiz HTML editor.
The easiest workflow is to host this small site or distribute the HTML file so students open it in a browser.
